# DependencyLogFormatter Usage Guide

## Overview

The `DependencyLogFormatter` is a specialized formatter for dependency tracking logs generated by the infinite render debugging system. It provides rich, interactive formatting for dependency change logs, circuit breaker events, and performance warnings.

## 🎯 **Supported Log Types**

### **1. Dependency Changes** (`🔄`)

Shows when component props/dependencies change:

```javascript
🔄 [ComponentName] Dependencies changed: {
  callback: { from: function, to: function },
  data: { from: {...}, to: {...} }
}
```

### **2. Function Recreation** (`📝`)

Highlights when functions are recreated on every render:

```javascript
📝 [ComponentName] onCallback: function changed (function → function)
📝 [ComponentName] onUpdate: function changed (function → function) ⚠️ FREQUENT
```

### **3. Object Recreation** (`📦`)

Shows when objects/arrays are recreated:

```javascript
📦 [ComponentName] data: object changed
📦 [ComponentName] config: object changed ⚠️ FREQUENT
```

### **4. Render Warnings** (`⚠️`)

Performance warnings for excessive renders:

```javascript
⚠️ [ComponentName] High render count detected: 15
⚠️ [ComponentName] High render count detected: 25
```

### **5. Circuit Breaker Protection** (`🚨`)

Critical events when components are automatically disabled:

```javascript
🚨 [ComponentName] CIRCUIT BREAKER OPEN - Excessive renders detected: 16
🛑 [ComponentName] Hook disabled to prevent infinite loop
🔄 [ComponentName] Circuit breaker auto-restored
```

### **6. Emergency Stop Events** (`🛑`)

Global emergency protection activation:

```javascript
🚨 EMERGENCY STOP ACTIVATED - All protected hooks disabled
🛑 [ComponentName] Hook execution blocked (emergency stop active)
✅ Emergency stop deactivated - Hooks restored
```

## 🎨 **Visual Features**

### **Color-Coded Severity**

- **Blue** - Information (dependency changes)
- **Red** - Critical issues (function recreation, circuit breakers)
- **Orange** - Warnings (render count, object recreation)
- **Purple** - Hook execution events
- **Gray** - Primitive changes

### **Priority Highlighting**

- Critical and warning logs have **enhanced borders** and **glow effects**
- Severity badges: `CRITICAL`, `WARNING`, `NOTICE`, `INFO`
- Emergency events get **double border width** and **shadow highlighting**

### **Expandable Details**

Click any log entry to expand and see:

- **Changed Properties**: Detailed breakdown of what changed
- **From/To Values**: Visual diff of dependency changes
- **Raw Data**: Full JSON data for advanced debugging
- **Fix Suggestions**: Contextual troubleshooting tips

## 💡 **Built-in Fix Suggestions**

### **Function Recreation Issues**

```
💡 Fix Suggestion:
Use useCallback() to memoize this function with stable dependencies
```

### **Object Recreation Issues**

```
💡 Fix Suggestion:
Use useMemo() to memoize this object or array with stable dependencies
```

### **Render Warnings**

```
⚠️ Performance Warning:
This component is re-rendering frequently. Check for unstable dependencies.
```

### **Circuit Breaker Events**

```
🚨 Circuit Breaker Activated:
Component disabled to prevent infinite loop. Will auto-restore shortly.
```

## 🔧 **Usage in Debug System**

### **Automatic Integration**

The formatter automatically activates for logs with:

- **Debug Point**: `"dependencies"`
- **Generated by**: `useWhyDidYouUpdate`, `useRenderTracker`, `useCircuitBreakerTracker`

### **Manual Usage**

```typescript
import { DependencyLogFormatter } from "@workspace/surface";

// Use in custom debug panels
<DependencyLogFormatter log={dependencyLog} />
```

### **Example Log Entry**

```typescript
const dependencyLog: DebugLogEntry = {
  timestamp: Date.now(),
  level: "warn",
  point: "dependencies",
  message: "🔄 [MyComponent] Dependencies changed:",
  data: {
    onCallback: { from: Function, to: Function },
    data: { from: {...}, to: {...} }
  },
  sessionId: "default",
};
```

## 🚀 **Integration with Debug Panel**

### **Real-time Display**

- Logs appear immediately in `DebugExternalPanel`
- Available in `DebugLogsList` with full history
- Supports copy/export functionality for sharing

### **Filtering Support**

- Filter by debug point: `dependencies`
- Search within component names
- Filter by severity level

### **Performance Optimized**

- Lazy rendering for large log volumes
- Efficient expand/collapse state management
- Memory-conscious with log rotation

## 📊 **Component Analysis Features**

### **Dependency Change Breakdown**

For complex dependency changes, the formatter shows:

- **Property name** with appropriate emoji (`📝` for functions, `📦` for objects)
- **Type detection** (function/object/primitive)
- **Before/after values** with syntax highlighting
- **Change frequency** indicators (`⚠️ FREQUENT` for rapid changes)

### **Troubleshooting Context**

Each log type includes contextual information:

- **Component name** extracted from message
- **Timestamp** for correlation
- **Severity assessment** based on log content
- **Interactive expansion** for detailed analysis

## 🔍 **Debug Workflow Integration**

### **1. Enable Dependency Tracking**

```javascript
surfaceDebug.enable("dependencies");
surfaceDebug.deps.normal();
```

### **2. Monitor in Debug Panel**

- Open debug panel to view formatted logs
- Expand entries to see detailed breakdowns
- Follow fix suggestions for problem resolution

### **3. Export for Analysis**

- Use copy functionality to export logs
- Share formatted output with team members
- Include in bug reports for faster resolution

The `DependencyLogFormatter` transforms raw dependency tracking data into actionable insights, making infinite render debugging faster and more intuitive! 🎯
